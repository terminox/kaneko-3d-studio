# Design files and reprints

Type: grilling
Status: open
Blocked by: 06
Map: [Clicker Generator](../map.md)

## Question

How are Designs saved so any Order can be reprinted identically?

Decide the Design file format and schema, where Designs are stored and how they're named (by Order number?), and how one Order with several Designs is grouped. Decide how a saved Design still produces the *same* geometry after the generator changes (generator version stamp, migrations, or frozen Fit Calibration values).
